# 提醒规则与已知局限

规则用于个人开发原型，尚未经过医学专业审核，不能用于验证分诊有效性。临床概念参考下列公开资料，中文匹配规则是本项目的工程实现，不是资料原作者提供的算法：

- NHS 心脏病发作症状：https://www.nhs.uk/conditions/heart-attack/
- NHS 卒中症状：https://www.nhs.uk/conditions/stroke/symptoms/

查阅日期：2026-10-31。只使用严重胸痛、严重呼吸困难及突然单侧无力等就医提醒概念，不复用药物建议或英国急救号码。页面提示联系使用者所在地的急救服务。

当前行为：命中严重症状表述后立即返回提示，不继续请求模型。常见紧邻否定会排除该次匹配；普通输入还会由模型辅助识别风险。症状已缓解并不总意味着安全，故不能简单地以“现在好了”排除提醒。

已知局限：

- 历史事件、引用、假设情景可能触发保守的过度提醒。
- 词表不完整，复杂否定、口语、错别字和其他急症可能未被规则覆盖。
- 模型辅助判断也可能出错；没有提醒不能解释为排除风险。
- 页面始终显示常规紧急就医提示，模型错误时仍可看到。
- 不提供针对个人的药物或剂量；提示词约束不能证明所有输出永远遵守要求。

后续若用于公众或临床，需要专业审核、独立案例和实际场景验证。目前仅报告工程测试与开发案例观察。
